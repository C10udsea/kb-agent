# 无线通信与信道

## 电磁波传播机制

无线信号以电磁波形式传播，主要机制包括直射、反射、绕射和散射。直射是视距路径；反射发生在建筑物、地面等尺寸远大于波长的物体表面；绕射使电波能够越过障碍物边缘到达阴影区域；散射由树叶、粗糙表面等大量小尺寸物体引起。

实际接收信号是直射波、反射波和散射波等多个分量的叠加，因此接收功率和相位会随位置发生复杂变化。

## 自由空间路径损耗

在理想的自由空间中，接收功率随距离增加而下降。Friis 公式表明，接收功率与距离的平方成反比。用对数表示时，路径损耗随距离每增加一倍增加约 6 dB。

路径损耗指数 n 用来描述不同环境的衰减速度：自由空间 n 约等于 2，城市宏蜂窝环境 n 通常在 2.7 到 3.5 之间，室内环境 n 可能小于 2，具体取决于障碍物和波导效应。

## 大尺度衰落与小尺度衰落

大尺度衰落描述接收功率随距离和大型障碍物产生的缓慢变化，由路径损耗和阴影衰落组成。阴影衰落由建筑物、山体遮挡引起，通常服从对数正态分布。

小尺度衰落描述接收信号在很短距离或很短时间内由于多径叠加产生的快速起伏。接收机移动几十厘米，相位关系就可能明显改变，信号幅度可能变化数十分贝。

## 多径效应

发射信号经多条路径到达接收机，各径的幅度、相位和时延不同。多径会引起码间串扰，即前一符号的延迟副本落入后一符号的判决区间。

描述多径的两个重要参数是时延扩展和相干带宽。时延扩展表示多径分量到达时间的展宽程度，相干带宽近似等于时延扩展的倒数。若信号带宽远小于相干带宽，信道表现为平坦衰落；若信号带宽大于相干带宽，则表现为频率选择性衰落，不同频率分量衰落不同，需要均衡或 OFDM 等抗多径技术。

## 多普勒效应

接收机与发射机之间相对运动时，接收信号频率会发生偏移，称为多普勒频移。多普勒扩展与移动速度成正比。当符号持续时间远小于信道相干时间时，信道在一个符号内基本不变，称为慢衰落；否则称为快衰落。高速移动场景下多普勒频移显著，需要更强的载波同步和信道估计。

## 分集技术

分集利用多个统计独立的衰落副本提高可靠性。空间分集使用多根接收天线或发射天线；频率分集在不同频率上重复发送信息；时间分集在不同时间重复发送信息并配合交织编码。接收端用选择合并、等增益合并或最大比合并把多个副本组合起来，其中最大比合并性能最好。

## OFDM 原理

OFDM 把高速数据流分配到大量相互正交的子载波上并行传输，每个子载波的符号持续时间大大延长，从而减弱多径引起的码间串扰。相邻子载波频谱虽然重叠，但满足正交性，可以无干扰分离。

OFDM 发送端通过 IFFT 一次生成所有子载波信号，接收端通过 FFT 恢复各子载波数据。循环前缀插入在符号前，用来吸收多径时延并保持子载波正交性。OFDM 对频率偏移敏感，载波频偏会破坏子载波正交性，造成子载波间干扰。

## MIMO 技术

MIMO 在发射端和接收端同时使用多根天线。空间复用把不同数据流放在不同空间信道上并行传输，使容量随天线数近似线性增长；空间分集则发送相同数据的多个副本，提高链路可靠性。MIMO 系统的容量增益和分集增益与信道矩阵的秩和相关性有关。

大规模 MIMO 使用几十甚至上百根天线，通过波束赋形把能量集中到目标用户，是现代移动通信提高频谱效率的关键技术。

## 无线信道容量

单入单出系统的容量遵循香农公式。MIMO 系统在信道矩阵良好、信道状态信息可用时，容量可以随收发天线数中的较小者近似线性增长。实际系统中，导频开销、信道估计误差、干扰和相关信道都会使容量低于理论值。
