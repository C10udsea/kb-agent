# 通信原理基础

## 通信系统的基本模型

一个完整的通信系统包含信源、发送设备、信道、接收设备和信宿五个部分。信源产生消息，发送设备完成编码和调制，把消息变换成适合在信道中传输的信号；接收设备完成解调和解码，尽量恢复原始消息；信宿是信息的最终接收者。

噪声和干扰主要来自信道。通信系统设计的核心目标，就是在给定带宽、功率和信道条件下，尽可能提高传输速率并降低误码率。

## 模拟通信与数字通信

模拟通信直接传输连续变化的信号，例如传统调幅广播和调频广播。数字通信先对消息进行模数转换和信源编码，再传输离散的数字符号。数字通信的主要优点是抗干扰能力强、便于加密、便于差错控制，并且可以用再生中继消除噪声积累，因此现代通信系统几乎都采用数字传输。

## 基带传输与频带传输

基带传输是指不经过载波调制，直接把数字基带信号送入信道，常见于短距离有线通信和数字电路之间。频带传输则把基带信号搬移到高频载波上，使其适应无线信道或远距离有线信道。

常见的数字基带码型包括单极性不归零码、双极性不归零码、曼彻斯特码和差分编码。码型选择会影响信号的直流分量、定时恢复能力和抗噪声性能。

## 数字调制方式

数字调制用基带数字信号控制载波的幅度、频率或相位。

1. ASK（幅移键控）：用不同载波幅度表示 0 和 1，实现简单但抗噪声能力差。
2. FSK（频移键控）：用不同载波频率表示数字符号，抗幅度干扰能力较强，但占用带宽较大。
3. PSK（相移键控）：用不同载波相位表示数字符号，常见的有 BPSK、QPSK。相同误码率下 PSK 所需的信噪比通常低于 ASK 和 FSK。
4. QAM（正交幅度调制）：同时调制幅度和相位，例如 16QAM、64QAM。符号速率相同时，QAM 阶数越高传输比特率越高，但星座点间距变小，抗噪声能力下降。

## 误码率与信噪比

误码率表示接收端判决错误的比特数占总比特数的比例。信噪比越高，误码率通常越低。不同调制方式的误码率曲线不同：在相同误码率要求下，BPSK 比高阶 QAM 需要更低的信噪比，因此信道差时应选择低阶调制，信道好时再用高阶调制提高速率。

实际系统会根据信道质量动态调整调制与编码方案，这称为自适应调制编码。

## 香农公式

香农公式给出了带限高斯白噪声信道的容量上界：

```text
C = B * log2(1 + S/N)
```

其中 C 是信道容量，单位 bit/s；B 是带宽，单位 Hz；S/N 是信噪比。香农公式说明：带宽越大、信噪比越高，信道容量越大。它给出的是理论极限，实际系统只能接近这个上界，无法超过。

## 信源编码与信道编码

信源编码用于去除消息中的冗余，降低数据量，例如霍夫曼编码和算术编码。信道编码则人为增加可控冗余，使接收端能够发现并纠正传输错误，例如奇偶校验码、循环冗余校验码、卷积码、Turbo 码和 LDPC 码。

香农指出，只要信息传输速率低于信道容量，就存在一种编码方式可以使误码率任意小。现代信道编码正是朝着这个理论极限逼近。

## 同步技术

数字通信接收端需要完成载波同步、符号定时同步和帧同步。载波同步恢复本地载波的频率和相位；符号定时同步确定最佳采样时刻；帧同步找到一帧数据的起始位置。同步性能直接影响误码率，很多接收机先进行同步再解调。

## 多路复用

多路复用让多个用户共享同一信道。FDM 按频率划分信道，TDM 按时间划分信道，CDM 用相互正交的扩频码区分用户，OFDM 则把宽带信道划分为大量相互正交的子载波。多址技术可以看作多路复用在多用户场景下的应用。
